# Bike Parking 🚲

Aplicación Android para localizar aparcamientos de bicicletas de forma rápida y sencilla en Zaragoza.

## 📱 Versión

**v0.1.0**

## ⬇️ Descargar

La aplicación está disponible para Android.

## 🛠️ Tecnologías

- Angular
- Ionic
- Capacitor
